#+title: Schaake Solutions Website

Source for [[https://www.schaake.solutions][www.schaake.solutions]], the single-page marketing site for Schaake Solutions, LLC. It presents Mark Schaake's consulting services: fractional CTO and technical leadership, applied AI implementation, and architecture and delivery consulting.

* Stack

- Astro 7 (static output) with Tailwind CSS 4 via =@tailwindcss/vite=
- sharp for image optimization
- pnpm; Node 22.23.4 or newer

* Run

#+begin_src sh
pnpm install
pnpm dev        # http://localhost:4321
pnpm build      # outputs dist/
pnpm preview    # serve dist/ locally
#+end_src

* Test

#+begin_src sh
node --test tests/
#+end_src

The tests check the homepage copy in =src/pages/index.astro= and =src/layouts/Layout.astro=, so update them together with any copy change.

* Deploy

Hosted on Vercel. Pushing =master= to =origin= deploys to production through Vercel's GitHub connection. =pnpm run deploy= (=vercel --prod=) is a manual alternative. Plain =pnpm deploy= is a different pnpm command and does not work here.

* Layout

- =src/pages/index.astro=: the page
- =src/layouts/Layout.astro=: header, navigation, footer, metadata
- =src/components/=: small Astro components (logo, link)
- =src/assets/=, =public/=: images and static files
- =tests/=: copy tests
